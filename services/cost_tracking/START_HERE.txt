PRICING REFERENCE
================================================================================

Claude Model Pricing (per 1M tokens):
  Haiku:    $0.80 input  / $2.40 output
  Sonnet:   $3.00 input  / $15.00 output
  Opus:     $15.00 input / $45.00 output
  Opus 4.8: $12.00 input / $36.00 output
  Gemini:   $0.075 input / $0.30 output

Formula: (input_tokens / 1M) × input_price + (output_tokens / 1M) × output_price

Example: Sonnet (5000 input + 3500 output)
  (5000 / 1000000) × $3.00 = $0.015
  (3500 / 1000000) × $15.00 = $0.0525
  Total: $0.0675
